# 实验目录

`labs/` 保存可以执行、比较和复现的实验。长期概念说明放在 `docs/`，按日期变化的过程放在 `logs/`。

## 当前实验

- [DeepSelect TopK](topk/README.md)：先定义接口契约，再准备 AMD/HIP 环境中的最小正确性验证。

## 实验记录要求

每个实验至少有：

- 研究目标和当前状态；
- 输入输出契约；
- 实际环境与版本；
- 正确性结果；
- 性能结果及测量方法；
- 失败和跳过项；
- 对应上游 commit 与讨论链接。

只有实际执行并通过的测试才能写成“通过”。性能数据必须来自同一环境中的可重复测量，并保留输入规模、预热方式、重复次数和同步方式。
